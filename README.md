# Vastu Studio

Редактор планов и Васту-разметки для Cloudflare Workers static assets.

Файлы сайта и `wrangler.jsonc` размещены в корне репозитория.

## Основной и тестовый сайты

| Ветка GitHub | Worker Cloudflare | Адрес |
| --- | --- | --- |
| `main` | `vastumap` | https://vastumap.a-m-nizamov.workers.dev/ |
| `VastuStudio-DEV` | `vastumap-dev` | https://vastumap-dev.a-m-nizamov.workers.dev/ |

В `main` поле `name` в `wrangler.jsonc` равно `vastumap`; в `VastuStudio-DEV`
оно должно оставаться `vastumap-dev`. При слиянии веток сохраняйте имя Worker
для целевого сайта. Команда публикации: `npx wrangler deploy`.

Изменения сначала проверяются на DEV и затем переносятся в `main` через Pull
Request. Автосохранение и проекты в браузере у этих сайтов раздельные.

## Локальный запуск

В корне проекта выполните:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765`. Установка зависимостей и сборка не нужны.

## Сохранение и восстановление

- Автосохранение хранится в текущем браузере отдельно для каждого адреса сайта.
  JSON-файл остаётся способом перенести проект между браузерами и компьютерами.
- Если при открытии найдена автокопия, она защищена до выбора «Восстановить»
  или «Продолжить текущий проект». Второй вариант заменяет её текущей сценой.
- Отмена и повтор действия обновляют автокопию. При уходе со страницы ожидающее
  сохранение выполняется сразу. Если для автокопии нет места, сохраните JSON-файл.
- Перед открытием JSON проверяются данные проекта. Ошибка не должна менять
  текущую сцену, историю или сохранённую автокопию.
- Размеры скрытых сеток сохраняются независимо от видимости. Если старый файл
  уже содержит нулевые размеры скрытой сетки, используются значения 480×480;
  исходный размер из такого файла определить нельзя, его нужно проверить вручную.

## Проверка изменений сохранения

1. Создайте надпись, дождитесь автосохранения, перезагрузите страницу. Поиск в
   каталоге не должен менять найденную автокопию; кнопка восстановления возвращает
   надпись.
2. Отмените добавление надписи, дождитесь сохранения и перезагрузите страницу.
   После восстановления отменённая надпись не должна появляться.
3. Измените размеры сетки, скройте её, сохраните JSON, откройте его и покажите
   сетку. Размеры должны сохраниться.
4. Попробуйте открыть файл с `{"labels":[null]}`. Должно появиться сообщение об
   ошибке, а текущая сцена и автокопия должны сохраниться.
